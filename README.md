# the sovereign library

> Five books, never more. Print-minimal by constitution: one file per
> book, no ornament, the body only — paper is the sand, and the fleet
> does not waste the sand. A book is admitted only when it is held AND
> read; the gate is NAND by design — the shelf refuses to print what has
> not been read. NOT/NAND — read it yet?

The print discipline: **ALWAYS max 5 books**. The shelf rotates; when a
sixth book begs admission, one of the five must leave the print canon
(its text stays, its print license lifts). The invariant protects the
operator's hands and the sand's patience.

## the rule of the five

1. Max five printed books, always. The count is the invariant.
2. Each book is a single plain-text/markdown file — the print body, no
   cover art, no imprint, no half-page apologia. The paper goes to the
   sentences.
3. A book enters the shelf when it is HELD (in some repo, 1:1 or
   linked). It enters the PRINT canon only when the operator marks READ.
4. When a sixth arrives, the least-read of the five steps out of the
   print canon. The text never leaves; the paper sleeps.
5. The shelf is public, the gate is honest, and the colophon is always
   the same: fine touch from within, vaked.dev.

## the ultralove editions

Outside the five, never inside them: the poems and one-offs the print canon
has no room for. `editions/ultralove/your-name.md` — *YOUR NAME, my
favourite anime depth*, for Jasmin — is the first: a folded sheet, time and
space wrapped back to 0, where Zen was felt again. The editions do not
rotate the shelf; they sit beside it.
