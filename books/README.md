# books — the print canon

> Five books, never more. This directory holds the canon's bodies: full
> texts, one file each, print-minimal by constitution. The gate is NAND:
> a book is printable only when HELD and READ — and the READ bits open
> with the reader's eyes.

## the rules

1. Max five printed books, always; when a sixth begs admission, the
   least-read of the five leaves the print canon (text stays, license
   lifts).
2. Each book is a single plain file — the print body, no cover art, no
   imprint. The paper goes to the sentences.
3. The READ bits are the reader's: a book not yet read prints nothing
   but this index. NOT/NAND — read it yet?

## the roots

Each book's root is named, not guessed — `../SOURCES.md` is the source
garden that wires the five to where they are held from and the garden back
to every room (three of the five are mr standardgalactic's hand). The
vault-side index of the garden is
`8b-is/raw_research/standardgalactic-wire-absorbed.md`. If a root moves,
the shelf re-wires before the next print.

## the shelf's law

The corpus above all (the box sitting, 2026-09-18); the colophon is
